# 八股学习站

包含 Java 八股 与 Agent与大模型 两个学习模块的静态学习页，可在 GitHub Pages 上免费访问。学习进度保存在你自己的浏览器里。

打开 [学习首页](https://cyfcyfff.github.io/bagu-site/) 即可使用。

本地预览：在本目录启动静态服务后打开 `index.html`，例如 `python3 -m http.server 8080`。
